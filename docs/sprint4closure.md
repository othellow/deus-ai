# Sprint Retrospective

## What Went Well

- Frontend integrated seamlessly with the existing backend.
- Modular architecture simplified frontend development.
- Responsive design improved accessibility across devices.
- User experience benefited from a clean and minimalist interface.
- JavaScript client remained lightweight and framework-independent.
- Agile iterations enabled continuous refinement throughout development.

---

## Challenges Encountered

- Coordinating frontend and backend communication.
- Managing browser CORS restrictions.
- Designing an interface that balanced simplicity with functionality.
- Maintaining compatibility with future website integration.
- Refining user interaction without introducing unnecessary complexity.

---

## How Challenges Were Addressed

- Enabled CORS support within FastAPI.
- Implemented asynchronous API communication using JavaScript.
- Adopted a responsive design with progressive enhancement.
- Preserved a modular architecture separating frontend and backend concerns.
- Focused on incremental UI improvements while maintaining system stability.
